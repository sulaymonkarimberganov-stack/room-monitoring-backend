## 💡 Dizayn Qarorlari

1. **STANDARD** - Eng oddiy xona, yashil = toza, qizil = iflos
2. **LUXURY** - Premium xona, ko'k rang (mehmonxona brendi)
3. **SUITE** - Eng yuqori darajadagi xona, binafsha + OLTIN border (VIP)
4. **MAINTENANCE** - Ta'mirlash, kulrang (faol emas)

## 🔄 Holat O'zgarishi Animatsiyasi

```
DIRTY (Qizil) → OCCUPIED (To'q sariq) → CLEAN (Yashil)
     ↓                ↓                      ↓
  Iflos         Tozalanmoqda              Toza
```

## 📐 O'lchamlar

- Default: `40x40 px`
- Cleaner Dashboard: `48x48 px`
- Admin/Manager Dashboard: `50x50 px`
- Border radius: `12 px`
- Border width: `1.5 px`
- Ikonka o'lchami: `size * 0.5`
